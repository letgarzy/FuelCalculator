Aplicação Android desenvolvida em Kotlin para calcular o custo estimado de uma viagem com base na distância, consumo do veículo e preço do combustível.

## 📱 Sobre o projeto
  O Fuel Calculator foi desenvolvido durante meu processo de aprendizagem de desenvolvimento Android com Kotlin.
  A aplicação permite ao utilizador informar:
- ✅ Entrada do preço do combustível por litro
- ✅ Entrada do consumo médio do veículo (km/L)
- ✅ Entrada da distância da viagem (km)
- ✅ Cálculo automático do custo total de combustível
- ✅ Tela de resultado com resumo completo dos dados informados
- ✅ Opção de recalcular sem reiniciar o app
  
## 🎯 Objetivo

## 🧮 Como funciona
O cálculo utilizado é:

$$\text{Custo Total} = (\frac{\text{Distância}}{\text{Consumo por Litro}}) \times \text{Preço do Combustível}$$

## 📚 O que aprendi
Durante o desenvolvimento deste projeto, tive contacto com navegação entre diferentes Activities, passagem de dados através de Intents e construção de interfaces em XML.
Também enfrentei problemas relacionados com layouts, IDs, padding e Window Insets. A resolução desses problemas ajudou-me a compreender melhor a relação entre o código Kotlin e os elementos definidos no XML.
